## ⚡ Executive Thesis & Architecture

The structural shift is that ChatGPT and personal AI assistants are moving toward becoming the **distribution, identity, and agent execution layer** for software. 

The web evolved:
```
Website ➔ Mobile App ➔ API ➔ Agent Interface
```

Previously, humans learned the software interface. Now, **software learns the business**. Ark Forge provides the machine-facing operational layer every business needs once customers dispatch AI agents instead of clicking through websites.

```text
ChatGPT / Autonomous Client
            ↓
  Identity / Authorization
            ↓
     Ark Labor Cloud
            ↓
   Mission Orchestrator
   ├── Susie Signal (Lead Intelligence)
   ├── Headless Browser Worker (DOM Probes)
   ├── ProofAI Verification Worker (Merkle Hash)
   └── Report Worker (Actionable Insights)
            ↓
   Cryptographic Proof / Audit Log
            ↓
   Streamed Result to ChatGPT
```

## 🏛️ The Three Core Pillars

### 1. 🥇 Agent-Native Conversion Studio (#1 Revenue Gem)
* **The Picks-and-Shovels Play**: Inspects existing SaaS, medical clinic workflows, or field-service portals and translates high-friction user journeys into machine-executable ChatGPT tools.
* **The 90-Second Proof**:
  * *Before*: Open SaaS ➔ search menus ➔ fill 12 form fields ➔ solve captcha ➔ enter credit card ➔ wait 24h.
  * *After*: User tells ChatGPT desired outcome ➔ agent calls Ark Gateway ➔ structured action executed in 1.4s with cryptographic receipt.
* **Outputs**:
  * OpenAPI 3.1 YAML ChatGPT Actions manifest
  * Model Context Protocol (MCP) tool declarations
  * Delegated Agent JWT & OAuth 2.0 PKCE auth configs
  * Deterministic safety guardrails & Human-in-the-Loop (HITL) triggers

### 2. 💎 Ark Labor Cloud as the Agent Runtime Behind ChatGPT (#1 Strategic Gem)
* **Workforce Backend**: Gives ChatGPT access to persistent, specialized domain workers rather than treating it like a standalone chatbot.
* **Flagship 48-Hour Validation Demonstration**:
  * Real-time automated audit of the 30 best med spas in Minneapolis.
  * Evaluates the 7 failure links: `Trigger → Discovery → Decision → Action → Evidence → Verification → Settlement`.
  * Identifies prime conversion targets with documented revenue leakage.
* **Persistent Worker Fleet**:
  * **Susie Signal**: Market research, deep footprint mapping, and prospect qualification.
  * **Browser Worker**: Headless Chromium DOM & booking widget traversal.
  * **ProofAI Oracle**: Cryptographic Merkle evidence attestation.
  * **Competitive Intel Worker**: Real-time pricing & feature drift extraction.

### 3. 🕵️ AgentReady Certification + Monitoring (#1 Hidden Gem)
* **The SEO of the Agent Era**: Continuous synthetic agent observability answering: *Can agents actually use this business correctly and safely?*
* **The 6-Stage Synthetic Agent Journey**:
  1. **Discover**: `robots.txt`, `llms.txt`, JSON-LD schema, search bot indexing.
  2. **Understand**: Machine-readable pricing & structured service taxonomy.
  3. **Authenticate**: Delegated agent bearer tokens vs. interactive captcha traps.
  4. **Act**: Structured API endpoints vs. untyped DOM clicks.
  5. **Verify**: Deterministic receipts & Merkle audit trails.
  6. **Pay**: Agentic cards / Stripe Agent Toolkit vs. 3D-Secure browser lockouts.
* **Outputs**:
  * Verifiable **AgentReady Score (0–100)** and Grade badge.
  * 1-Click **SchemaForge Remediation Patches**.
  * Continuous heartbeat probe monitoring latency, uptime, and schema drift.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- A Google Gemini API Key

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/techshare101/arkforge.git
   cd arkforge
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables:
   ```bash
   cp .env.example .env.local
   # Add your GEMINI_API_KEY
   ```

4. Run local development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to view the application.
